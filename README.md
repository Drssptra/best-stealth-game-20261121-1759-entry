Lantern Thief — a top-down 2D stealth game: sneak through a night museum garden, steal the golden relic, and slip past patrolling lantern guards with visible vision cones to the glowing exit, unseen.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — just static files.
